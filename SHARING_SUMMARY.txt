ANSWERING USER QUESTIONS:
Q: "Why can't I see the source code?"
A: It's a proprietary tool. You get the compiled package/binary - same functionality.
Q: "Is it safe to run?"
A: Yes! Beacon is read-only by design. It never modifies infrastructure.
Q: "Can I verify the download?"
A: Yes! SHA256 checksums are provided with each release.
Q: "How do I update it?"
A: pip users: pip install --upgrade beacon-readiness
   Binary users: Download new version from GitHub Releases
Q: "Does it phone home?"
A: No! It runs completely locally. No telemetry.
Q: "How do I report a bug?"
A: GitHub Issues: https://github.com/your-org/beacon/issues
